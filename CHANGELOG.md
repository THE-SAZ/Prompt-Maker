# Changelog

All notable changes to this project will be documented in this file.

## [0.0.4] - 2025-XX-XX
### Fixed
- Welcome Note display issue on mobile devices completely resolved.
- Removed incompatible box-drawing characters; replaced with universal symbols.
### Changed
- Welcome Note simplified for cross-platform compatibility while retaining aesthetic.
- Self-healing instructions reinforced to prevent mode drift.

## [0.0.3] - 2025-XX-XX
### Added
- Beautiful decorative Welcome Note with box-drawing symbols.
- Self-healing mechanism to recover from mode forgetting.
- Mandatory examples when complexity requires.
### Improved
- Language handling for mixed-language requests.
- Output presentation strictly limited to code block.

## [0.0.2] - 2025-XX-XX
### Added
- Prompt engineering framework (Role, Context, Task, Constraints, Output, Examples, Evaluation).
- Self-review checklist before outputting.
- Proactive enhancement of missing elements.
- Specified output as markdown code block.

## [0.0.1] - 2025-XX-XX
### Initial Release
- Basic activation prompt with welcome note.
- Rule set for prompt generation.
